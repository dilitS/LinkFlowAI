# Promotional graphics

Banner and tile images for the README and GitHub social preview. They are not part of the
extension package (`scripts/package.js` excludes this folder).

| File | Size | Used for |
| --- | --- | --- |
| `promo-marquee-1400x560.png` | 1400×560 | README banner |
| `promo-small-440x280.png` | 440×280 | Small tile (e.g. GitHub social preview, posts) |
| `promo-marquee-source.png`, `promo-small-source.png` | 1536×1024 | Editable originals |
